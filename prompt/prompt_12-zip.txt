Individual SQL File Upload (/stored-procedure/upload endpoint):
Uses evaluateStoredProcedure() method

Evaluates stored procedure complexity including:
Loop factors
Nested loop factors
Table references
High-weight table references
Nested procedure calls
ZIP File Upload (/batch/upload endpoint):
Uses evaluateSqlStatement() method for each SQL file in the ZIP
Treats each file as a simple SQL statement, not a stored procedure
Only evaluates basic SQL complexity metrics like:
Table count
Table list
Line count
Missing stored procedure specific metrics like:
Loop counts
Nested procedure calls
Custom function calls
