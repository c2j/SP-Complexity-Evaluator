Fixed Procedure Identification: We updated the regular expressions in both GaussStoredProcedureParser and OracleStoredProcedureParser to correctly identify procedures in package bodies, even when they have multiple begin/end blocks or when they end with END; instead of END procedure_name;.
Fixed Line Count Calculation: We modified the ComplexityEvaluationServiceImpl to calculate the line count for each procedure based on its source code, rather than using the total package line count for all procedures.
Fixed Table Identification: We enhanced the table detection logic in GaussComplexityEvaluator to identify all tables referenced in the SQL statements, including those in INSERT, UPDATE, DELETE statements, and those referenced in type declarations.
Fixed Self-Procedure Call Detection: We updated the code that checks if a procedure is calling itself to handle the case where the procedure name includes the package name.
