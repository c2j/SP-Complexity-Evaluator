欢迎使用SQL复杂度评估工具

本工具用于评估SQL语句和存储过程的复杂度，帮助您识别可能需要优化或重构的复杂查询。

主要功能

  • SQL语句评估 - 分析单个SQL语句的复杂度
  • 存储过程评估 - 分析整个存储过程的复杂度，包括嵌套调用
  • 批量SQL评估 - 通过ZIP文件批量处理多个SQL文件
  • 多方言支持 - 支持Oracle、Gauss和Hive SQL方言
  • 自定义评估因素 - 支持自定义函数列表、高权重表列表和高权重过程列表
  • 多种输出格式 - 支持JSON和Excel格式的结果导出

复杂度评估方法

SQL语句复杂度因素

  • 表数量 - 查询中引用的表数量
  • 连接数量 - JOIN操作的数量
  • WHERE条件 - WHERE子句中的条件数量
  • 子查询数量 - 嵌套的SELECT语句数量
  • 聚合函数 - COUNT、SUM、AVG等函数的使用
  • CASE表达式 - CASE...WHEN...THEN语句的使用
  • 集合操作 - UNION、UNION ALL、INTERSECT、MINUS操作的使用
  • GROUP BY - 分组操作的使用
  • ORDER BY - 排序操作的使用
  • 查询深度 - 嵌套查询的深度

存储过程额外复杂度因素

  • 循环 - FOR、WHILE、LOOP语句的使用
  • 嵌套循环 - 循环内部的循环
  • 自定义函数 - 用户定义函数的调用
  • 高权重表 - 对标记为高权重的表的引用
  • 嵌套过程 - 对其他存储过程的调用
  • 高权重过程 - 对标记为高权重的过程的调用
